# Memory Game

An interactive browser-based memory card game built using HTML, CSS, and JavaScript. Players must match pairs of cards while tracking their performance through attempt counts and completion time.

## Features

- Card matching gameplay
- Attempt counter
- Timer-based scoring
- Leaderboard displaying completion statistics
- Animated card flipping effects
- Responsive design
- Win detection and game completion tracking
- Interactive user feedback

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Web Designer

## What I Learned

This project improved my understanding of JavaScript event handling, DOM manipulation, timers, state management, game logic, and creating interactive user experiences.
